Protect a specific Chrome profile (e.g., "vamsi greeshma") with an in-browser password lock screen using Manifest V3.

The extension code is located inside the [`chrome-profile-lock/`](file:///d:/Projects/ChromeProfileLock/chrome-profile-lock) directory.
